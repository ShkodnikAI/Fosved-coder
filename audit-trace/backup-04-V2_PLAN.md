# FOSVED CODER V2.0 — План реализации

## Архитектурные принципы

### 1. Паттерн «Прокладка» (Middleware)
Модель НЕ знает о существовании инструментов. Ассистент молча:
- Подставляет содержимое файлов в контекст (prompt_injector)
- Извлекает команды записи/чтения из ответа (response_parser)
- Выполняет их, пользователь видит только итог

### 2. Двойной режим
- **Tool Calling** — для моделей с нативной поддержкой (Claude, GPT, Gemini)
- **Prompt Injection** — универсальный fallback для всех остальных (Qwen, Llama, Ollama)

### 3. Разделение экранов
- **Главный экран** — творческое обсуждение, скиллы, промпт-драфты, анкета
- **Экран проекта** — код, инструменты, git, файловое дерево

## Фазы реализации

### Фаза 1: Backend Core (python)
**1.1. core/response_parser.py** — полная переработка
- Убрать дублирование с agent.py
- Парсинг: `<file path="...">`, ```lang:path, ```diff, `<command>`, `<git>`
- Clean text для отображения пользователю
- ActionExecutor с полной обработкой всех типов действий

**1.2. core/prompt_injector.py** — усиление
- Автоматическая инъекция списка скиллов в контекст
- Умное усечение контекста с приоритетом ключевых файлов
- Динамическая анкета (вопросы от AI для сбора требований)

**1.3. core/agent.py** — переработка
- Единая точка обработки сообщений (убрать дублирование с router.py)
- Тихое зондирование моделей при старте
- Улучшенное маршрутизирование (по приоритету/сложности)
- Поддержка extended thinking (Claude Opus/Sonnet 4)

**1.4. core/memory.py** — очистка
- Удалить ChatThread (deprecated)
- Добавить таблицу Questionnaire (для динамической анкеты)
- Обновить таблицу Project (добавить поля для проектных карт)

**1.5. Очистка мёртвого кода**
- Удалить core/chat.py (deprecated)
- Убрать дублирующую маршрутизацию из router.py или agent.py

### Фаза 2: API (endpoints)
**2.1. api/endpoints.py** — реструктуризация
- Новые эндпоинты для экрана проектов
- Эндпоинты для динамической анкеты
- Эндпоинты для тихого зондирования
- Разбить на подмодули (опционально, в рамках одного файла)

**2.2. run.py** — обновление
- Новая логика WebSocket для двух экранов
- Обработка новых событий (анкета, зондирование)

### Фаза 3: UI (Frontend)
**3.1. ui/templates/index.html** — полная перестройка
- Навигация: главный экран / экран проекта
- Главный экран: чат + скиллы + промпт-драфты + анкета
- Экран проекта: файловое дерево + редактор + git + терминал
- Авто-переход между экранами

**3.2. ui/static/style.css** — обновление
- CSS-переменные для тем
- Компоненты для новых экранов
- Адаптивность

### Фаза 4: Новые функции
**4.1. Тихое зондирование**
- При старте → минимальный запрос к каждой модели
- Ответившая модель автоматически появляется в панели

**4.2. Динамическая анкета**
- AI задаёт адаптивные вопросы по проекту
- Ответы заполняют проектную карту
- Автоматическая генерация промпта из анкеты

**4.3. Авто-выбор скиллов**
- Список скиллов инжектится в системный промпт
- Модель сама выбирает нужные скиллы
